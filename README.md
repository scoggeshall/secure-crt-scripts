\# SecureCRT Scripts



Collection of SecureCRT Python scripts for network operations.



\## Repository Structure



\- `oui-lookup/` — offline MAC OUI to vendor lookup using `manuf.txt`

\- `cable-test/` — SecureCRT cable test script

\- `quick-logo-all/` — SecureCRT quick logo script



\## Notes



Each script is stored in its own folder so it can keep its code, documentation, and any supporting files together.
